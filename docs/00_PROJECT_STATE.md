# Project Summary

Project Name: Rezel

Rezel is a next-generation desktop AI operating intelligence built using Tauri, React, TypeScript, Rust, React Three Fiber, and Tailwind CSS v4.

The project is currently in the **foundation phase**. The engineering architecture has been established, the repository has been initialized, and the initial UI foundation has begun. Core AI functionality has **not** yet been implemented.

The guiding principle is to prioritize architecture, maintainability, security, and production quality over development speed.
