# Feature Development Workflow

## Purpose

Standard process for implementing new Rezel features.

---

# Phase 1: Planning

Agent must:

- Understand feature goal
- Check existing architecture
- Identify affected modules

---

# Phase 2: Design

Define:

- UI changes
- Backend changes
- Data flow
- Security concerns

---

# Phase 3: Implementation

Follow:

- Coding standards
- Design principles
- Existing architecture

---

# Phase 4: Testing

Verify:

- Application starts
- Build succeeds
- No errors
- Performance maintained

---

# Phase 5: Review

Reviewer checks:

- Code quality
- UX consistency
- Architecture impact

Only then mark complete.
