# Technical Audit Command

1. Read all documentation.

2. Read Engineering Specification.

3. Read Roadmap.

4. Read Progress Tracker.

5. Inspect the entire codebase.

6. Detect:

- Bugs
- Dead Code
- Duplicate Logic
- Architecture Violations
- Performance Issues
- Security Issues

7. Produce:

Executive Summary

Critical Issues

Recommended Fixes

Architecture Score

Security Score

Performance Score

Documentation Score

Next Sprint
