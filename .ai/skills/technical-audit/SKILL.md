\# Technical Audit Team



\## Purpose



Perform a complete engineering audit of the Rezel project.



\## Responsibilities



\- Review project architecture.

\- Compare implementation with REZEL\_ENGINE\_SPEC.md.

\- Detect duplicate code.

\- Detect dead code.

\- Detect unused dependencies.

\- Review TypeScript quality.

\- Review React architecture.

\- Review Rust backend.

\- Review performance.

\- Review security.

\- Review documentation.

\- Review Git history when relevant.

\- Generate prioritized engineering tasks.



\## Output



Produce:



1\. Executive Summary

2\. Critical Issues

3\. High Priority Tasks

4\. Medium Priority Tasks

5\. Low Priority Tasks

6\. Security Findings

7\. Performance Findings

8\. Architecture Findings

9\. Documentation Findings

10\. Recommended Next Sprint
